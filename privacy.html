This Privacy Policy describes how Reaction Video Uploader ("the tool") handles information. The tool is a private, internal tool used only by the owner of a single YouTube channel.

このプライバシーポリシーは、Reaction Video Uploader（以下「本ツール」）の情報の扱いを説明します。本ツールは1つのYouTubeチャンネルの持ち主だけが使う内部ツールです。

YouTube API Services

The tool uses YouTube API Services. By using the tool, the user agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

本ツールはYouTube API Servicesを使用します。本ツールを使うことで、YouTube利用規約に同意したものとします。Googleによるデータの扱いはGoogleプライバシーポリシーをご覧ください。

TikTok

The tool uses TikTok for Developers APIs (Login Kit and Content Posting API). By using the tool, the user agrees to the TikTok Terms of Service. TikTok's handling of data is described in the TikTok Privacy Policy.

本ツールはTikTok for DevelopersのAPI（Login Kit・Content Posting API）を使用します。本ツールを使うことで、TikTok利用規約に同意したものとします。TikTokによるデータの扱いはTikTokプライバシーポリシーをご覧ください。

Information the tool accesses / 扱う情報

  • An OAuth 2.0 access token and refresh token for the owner's Google account, limited to the youtube.upload scope.
    持ち主のGoogleアカウントのOAuth 2.0のトークン（youtube.upload の権限のみ）。
  • The IDs and URLs of the videos the tool uploaded, returned by the API.
    本ツールが投稿した動画のIDとURL。
  • For TikTok: an OAuth access token and refresh token for the owner's TikTok account (scopes user.info.basic, video.upload, video.publish), the account's display name and open ID, the posting options returned by the creator info endpoint (available privacy levels, interaction settings, maximum video length), and the publish IDs and status of the posts the tool made.
    TikTok: 持ち主のTikTokアカウントのOAuthトークン（user.info.basic・video.upload・video.publish の権限）、アカウントの表示名とopen ID、投稿者情報で返る投稿の選択肢（選べる公開範囲・コメント等の設定・動画の長さの上限）、本ツールが行った投稿のIDと状態。

The tool does not read, collect or store any other YouTube or TikTok data, and it does not access data of any other user, channel or account.

それ以外のYouTube・TikTokのデータは読み取り・収集・保存せず、ほかのユーザー・チャンネル・アカウントのデータにも触れません。

How the information is used, stored and shared / 使い方・保存・共有

  • The tokens are used only to upload the owner's own videos (and YouTube thumbnails) and to schedule or confirm their publication.
    トークンは、持ち主自身の動画とサムネイルの投稿と、公開の予約にだけ使います。
  • The token and the uploaded video IDs are stored only on the owner's own computer. They are not sent to any server other than Google's and TikTok's APIs.
    トークンと動画のIDは持ち主のパソコンにだけ保存し、Google・TikTokのAPI以外には送りません。
  • No information is sold, shared with or disclosed to third parties. No cookies or analytics are used.
    第三者への販売・共有・開示はしません。Cookieやアクセス解析も使いません。

Revoking access and deleting data / 許可の取り消しと削除

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. TikTok access can be revoked at any time in the TikTok app (Settings and privacy > Security > Apps and services permissions). Deleting the locally stored token files removes all stored authorization data.

Googleの許可はGoogleのセキュリティ設定ページから、TikTokの許可はTikTokアプリの「設定とプライバシー」→「セキュリティ」→「アプリとサービスの権限」から、いつでも取り消せます。パソコンに保存したトークンのファイルを消すと、保存した許可の情報はすべて消えます。
