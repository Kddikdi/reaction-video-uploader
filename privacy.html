This Privacy Policy describes how Reaction Video Uploader ("the tool") handles information. The tool is a private, internal tool used only by the owner of a single YouTube channel.

このプライバシーポリシーは、Reaction Video Uploader（以下「本ツール」）の情報の扱いを説明します。本ツールは1つのYouTubeチャンネルの持ち主だけが使う内部ツールです。

YouTube API Services

The tool uses YouTube API Services. By using the tool, the user agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

本ツールはYouTube API Servicesを使用します。本ツールを使うことで、YouTube利用規約に同意したものとします。Googleによるデータの扱いはGoogleプライバシーポリシーをご覧ください。

Information the tool accesses / 扱う情報

  • An OAuth 2.0 access token and refresh token for the owner's Google account, limited to the youtube.upload scope.
    持ち主のGoogleアカウントのOAuth 2.0のトークン（youtube.upload の権限のみ）。
  • The IDs and URLs of the videos the tool uploaded, returned by the API.
    本ツールが投稿した動画のIDとURL。

The tool does not read, collect or store any other YouTube data, and it does not access data of any other user or channel.

それ以外のYouTubeのデータは読み取り・収集・保存せず、ほかのユーザーやチャンネルのデータにも触れません。

How the information is used, stored and shared / 使い方・保存・共有

  • The token is used only to upload the owner's own videos and thumbnails and to schedule their publication.
    トークンは、持ち主自身の動画とサムネイルの投稿と、公開の予約にだけ使います。
  • The token and the uploaded video IDs are stored only on the owner's own computer. They are not sent to any server other than Google's APIs.
    トークンと動画のIDは持ち主のパソコンにだけ保存し、GoogleのAPI以外には送りません。
  • No information is sold, shared with or disclosed to third parties. No cookies or analytics are used.
    第三者への販売・共有・開示はしません。Cookieやアクセス解析も使いません。

Revoking access and deleting data / 許可の取り消しと削除

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. Deleting the locally stored token file removes all stored authorization data.

許可はGoogleのセキュリティ設定ページからいつでも取り消せます。パソコンに保存したトークンのファイルを消すと、保存した許可の情報はすべて消えます。

Contact / 連絡先

Questions about this policy can be sent through the Issues page of the repository that hosts this site.

このポリシーについてのお問い合わせは、このサイトのリポジトリの Issues からお願いします。
