Reaction Video Uploader

HomePrivacy PolicyTerms of Service

Reaction Video Uploader is a private, internal tool used only by the owner of a single YouTube channel. It uploads the owner's own manga reader-reaction videos to the owner's own YouTube channel using the YouTube Data API (YouTube API Services), and to the owner's own TikTok account using the TikTok Content Posting API (with Login Kit).

Reaction Video Uploader は、1つのYouTubeチャンネルの持ち主だけが使う内部ツールです。 持ち主が作った漫画の反応集動画を、YouTube Data API（YouTube API Services）で持ち主自身のYouTubeチャンネルに、TikTok Content Posting API（Login Kit）で持ち主自身のTikTokアカウントに投稿します。

What it does / できること

  • Uploads a finished video with its title, description, tags and custom thumbnail (videos.insert, thumbnails.set).
    完成した動画を、タイトル・説明文・タグ・サムネイルを付けて投稿します。
  • Schedules the video to be published at a fixed time each day (status.publishAt).
    毎日決まった時刻に公開されるよう予約します。
  • Requests only the https://www.googleapis.com/auth/youtube.upload scope.
    使う権限は動画の投稿（youtube.upload）だけです。

TikTok

  • Before each post, the tool shows a confirmation screen with the owner's TikTok account name, the video preview and caption, a privacy level that the owner chooses (no default), the comment / Duet / Stitch settings, the commercial content disclosure and TikTok's Music Usage Confirmation. Nothing is posted until the owner confirms.
    投稿の前に、TikTokのアカウント名・動画のプレビューとキャプション・本人が選ぶ公開範囲（最初からは決めない）・コメント／デュエット／ステッチの設定・宣伝の申告・TikTokの音楽の利用確認を出した確認画面を表示し、本人が確定するまで投稿しません。
  • Videos the owner confirmed are posted at the time the owner chose (Direct Post), or sent to the owner's TikTok inbox as drafts.
    確定した動画は、本人が選んだ日時に投稿するか、TikTokの受信箱（下書き）に送ります。
  • Uses the user.info.basic, video.upload and video.publish scopes only.
    使う権限は user.info.basic・video.upload・video.publish だけです。

Who can use it / 使う人

Only the channel owner, who authorizes the tool with their own Google account through OAuth 2.0. The tool is not offered, sold or distributed to anyone else, and it does not access other users' data.

使うのはチャンネルの持ち主だけで、本人のGoogleアカウントでOAuth 2.0の許可をして使います。ほかの人には提供・販売・配布せず、ほかのユーザーのデータにも触れません。
